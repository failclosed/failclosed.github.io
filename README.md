# FailClosed

Source for [failclosed.com](https://failclosed.com) — cybersecurity, automation, and AI-assisted tooling for IT and security professionals. Built with [Jekyll](https://jekyllrb.com) on the [Beautiful Jekyll](https://beautifuljekyll.com) theme.

## Local development

```
bundle install
bundle exec jekyll serve
```
